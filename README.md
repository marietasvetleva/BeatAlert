
# BeatAlert — Music Discovery & Concert Tracking

BeatAlert is a web application designed to help music enthusiasts stay informed about their favourite artists, new music releases, and upcoming concerts.

The application brings music-related information together in one place, making it easier for users to discover artists, explore discographies, and keep track of important updates.

## Overview

Music fans often rely on multiple platforms, such as Spotify, Ticketmaster and social media, to stay informed about their favourite artists.

BeatAlert addresses this problem by providing a centralised platform where users can follow artists, explore music releases and discover upcoming concerts.

## Key Features

- **Artist Search:** Search for artists and explore their music.
- **Artist Following:** Follow favourite artists to keep track of their updates.
- **Discography:** Browse artists' albums and releases.
- **Concert Information:** View upcoming concerts and events.
- **Dashboard:** Access relevant music and event information in one place.

## Software Design & Architecture

The application was developed with an emphasis on maintainability, separation of responsibilities, and structured software design.

The development process included:

- Creating conceptual and entity-relationship diagrams to design the database.
- Designing wireframes to define the user interface.
- Developing and updating UML class diagrams throughout implementation.
- Applying SOLID principles to improve code organisation and maintainability.
- Refactoring existing components and implementing exception handling.
- Using Git branches to manage development and changes.

## Testing & Quality Assurance

Testing was incorporated throughout the development process to improve application reliability.

- **Unit Testing:** Verified the behaviour of individual services and components.
- **Integration Testing:** Tested interactions between different application layers.
- **Acceptance Planning:** Defined acceptance criteria to evaluate the application's functionality.
- **Code Refactoring:** Improved maintainability and alignment with software design principles.

## Development Process

BeatAlert was developed iteratively using a structured software engineering approach.

1. **Research & Requirements:** Conducted a user interview, identified functional and non-functional requirements, and created a project plan.
2. **Design:** Developed database diagrams, wireframes, and UML class diagrams.
3. **Implementation:** Built the application and implemented its core functionality.
4. **Testing & Improvement:** Introduced unit and integration tests, improved exception handling, and refactored code.
5. **Finalisation:** Completed the planned functionality and updated the technical documentation.
